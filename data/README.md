# Data

Download train.csv, test.csv and sample_submission.csv from the [competition](https://www.kaggle.com/competitions/playground-series-s6e11/data) after accepting its rules. Put them here, or use the launcher's --data-dir option.

Competition data is CC BY 4.0 and is excluded from this repository.

V3 uses the [host-linked original dataset](https://www.kaggle.com/datasets/uditjain13/credit-card-fraud-detection-2026), licensed CC0. Run python -m scripts.download_original to download its CSV. Provenance and expected hashes are in reports/.
